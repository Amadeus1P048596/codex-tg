# v0.5.0-amadeus.1

`v0.5.0-amadeus.1` is a source release from the
[`Amadeus1P048596/codex-tg`](https://github.com/Amadeus1P048596/codex-tg)
community fork. It is based on upstream `mideco-tech/codex-tg` `v0.5.0`
(`41fa09a`).

## Highlights

- One Telegram activity card per turn with a four-second typing grace period,
  four-second edit throttle, activity aggregation, and in-place completion.
- One foreground session per chat/topic with `/home`, a durable `/inbox`,
  runtime-authoritative `/threads`, and background attention notices.
- Session administration through title-then-prompt creation, `/current`,
  user-owned `/title`, confirmed `/archive`, paginated `/unarchive`, and
  `/cancel`.
- Explicit Telegram writer handoff through acquire/release controls and guarded
  automatic idle release.
- Routed Telegram photo input, isolated spawned App Server homes, and Windows
  thread-archive path compatibility.

## Operator-Visible Changes

- The conversation emoji remains identity; Chinese text labels represent
  processing, needs-input, completed, failed, and cancelled states.
- Raw Tool/Output event spam is moved behind Details and explicit exports.
- Foreground progress stays focused while background terminal or needs-input
  events provide a direct switch action.
- Short in-place completions add one de-duplicated audible notice; fast terminal
  cards and separate long-result messages remain single-notice paths.
- Telegram can retain or safely release the App Server writer without silently
  queuing input during conflicts.

## Compatibility and Scope

- Codex App Server remains the live state authority.
- SQLite remains the durable local state store.
- The release retains Apache-2.0, the upstream `LICENSE`, and the upstream
  `NOTICE`; fork attribution and acknowledgements are recorded in
  [`FORK_NOTES.md`](../../FORK_NOTES.md).
- This publication is source-only. Upstream binary packages do not include the
  fork changes.
- The branch is intentionally based on upstream `v0.5.0`; later upstream `main`
  commits are not represented as part of this release.

## Validation

- `gofmt -l` over all Go files
- `git diff --check`
- `go test ./...`
- `go build -buildvcs=false ./...`
- targeted token, private-key, local-path, and runtime-artifact scans

The release preparation did not rerun the complete live Telegram matrix. See
[`docs/testing/validation-notes.md`](../testing/validation-notes.md) for the
existing live evidence and the paths still marked as pending.
